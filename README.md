# Customer Churn Analysis Dashboard

## 📌 Project Overview

Customer Churn Analysis Dashboard is a data analytics project developed to analyze customer churn patterns and identify customer segments with relatively higher churn.

The project uses the Telco Customer Churn dataset and provides both an Excel dashboard and an interactive Streamlit dashboard.

## 🎯 Objectives

- Analyze customer churn patterns
- Calculate important customer churn KPIs
- Compare churn across different customer segments
- Understand the relationship between monthly charges and churn
- Identify areas where customer retention can be improved
- Present insights through interactive dashboards

## 🛠️ Tools & Technologies

- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## 📊 Key KPIs

- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges
- Average Tenure
- Total Charges / Revenue

## 📈 Analysis Performed

The project analyzes churn based on:

1. Contract
2. Internet Service
3. Payment Method
4. Monthly Charges
5. Senior Citizen Status
6. Partner Status
7. Dependents

## 📊 Dashboards

### Excel Dashboard

The Excel dashboard contains KPI cards and visualizations for customer churn analysis.

### Streamlit Dashboard

The Streamlit application provides interactive filters and visualizations that allow users to explore churn patterns across different customer segments.

## 💡 Business Insights

The analysis helps identify customer segments with relatively higher churn and highlights areas where targeted customer-retention strategies can be considered.

## 🚀 How to Run the Streamlit Dashboard

### 1. Install Python

Make sure Python is installed on your system.

### 2. Install Required Libraries

Open Command Prompt/Terminal inside the project folder and run:

```bash
pip install -r requirements.txt
```

### 3. Run the Application

```bash
streamlit run app.py
```

The Streamlit dashboard will open in the browser.
